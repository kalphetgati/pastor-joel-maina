# Pastor Joel Maina - Portfolio Website

## Overview
A professional portfolio website for Pastor Joel Maina, showcasing his ministry services, counseling offerings, and spiritual guidance across various life areas.

## Features

- **Responsive Design**: Mobile-friendly layout that adapts to all screen sizes
- **Hero Section**: Engaging introduction with dynamic background slider
- **About Section**: Pastor's biography and ministry statistics
- **Team Section**: Display of team members
- **Ministry Services**:
  - Parenting Guidance
  - Business & Career Counseling
  - Fellowship Programs
  - Healing & Restoration
  - Marriage Counseling
- **Gallery**: Visual showcase of ministry activities
- **Testimonials**: Client reviews and success stories
- **Donations**: Easy M-Pesa payment integration
- **Contact Form**: Get in touch with the ministry
- **Social Media Integration**: Links to all social platforms

## Tech Stack

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS variables and Grid/Flexbox
- **JavaScript**: Interactive features and form validation
- **Font Awesome**: Icons library
- **Google Fonts**: Custom typography (Cinzel, Inter, Playfair Display)

## File Structure

```
├── index.html       # Main HTML file
├── styles.css       # Stylesheet
├── script.js        # JavaScript functionality
├── images/          # Image assets

```
